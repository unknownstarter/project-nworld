## 1. 사주팔자 기본 원리

### 1.1 네 기둥 (四柱)
사주팔자(四柱八字)는 생년·월·일·시의 네 기둥(四柱)에 각각 천간(天干)과 지지(地支) 2글자씩, 총 8글자(八字)로 운명을 분석하는 동아시아 전통 명리학 체계.

| 기둥 | 의미 | 천간(10) | 지지(12) |
|------|------|----------|----------|
| 년주(年柱) | 조상운, 사회적 환경 | 갑을병정무기경신임계 | 자축인묘진사오미신유술해 |
| 월주(月柱) | 부모운, 성장환경 | (년주 기반 계산) | (절기 기반) |
| 일주(日柱) | 본인, 배우자운 | (만세력 조회) | (만세력 조회) |
| 시주(時柱) | 자녀운, 말년운 | (일간 기반 계산) | (출생시간 기반) |

### 1.2 필수 입력 데이터
- **생년월일** (양력 또는 음력)
- **출생 시간** (2시간 단위 12지시, 정확할수록 좋음)
- **성별** (대운 순행/역행 결정)
- **출생 지역** (선택 - 진태양시 보정용, 경도 기반)

### 1.3 핵심 계산 요소
- **천간지지 60갑자** 순환 체계
- **절기(24절기)** 기반 월주 결정 (음력 날짜가 아닌 절기 기준)
- **오행(五行)**: 목(木), 화(火), 토(土), 금(金), 수(水)
- **음양(陰陽)**: 각 천간·지지의 음양 구분
- **십신(十神)**: 일간 기준 다른 글자와의 관계 (비견, 겁재, 식신, 상관, 편재, 정재, 편관, 정관, 편인, 정인)
- **지장간(支藏干)**: 지지 안에 숨겨진 천간
- **신살(神煞)**: 도화살, 역마살, 귀인 등 특수 요소

## 3. 궁합(compatibility) 알고리즘 설계

### 3.1 전통 궁합 판단 요소

#### 레벨 1: 기본 궁합 (구현 난이도: 낮음)
| 요소 | 설명 | 구현 방법 |
|------|------|-----------|
| 띠 궁합 (12지) | 삼합, 육합, 충, 형, 파, 해 | 룩업 테이블 |
| 오행 상생상극 | 목→화→토→금→수→목 순환 | 규칙 기반 |
| 천간합 | 갑기합, 을경합, 병신합, 정임합, 무계합 | 페어 매칭 |

| 요소 | 설명 | 구현 방법 |
|------|------|-----------|
| 일간 궁합 | 두 사람의 일간(Day Master) 관계 분석 | 십신 관계 계산 |
| 오행 보완성 | 한쪽에 부족한 오행을 상대가 채워주는지 | 오행 분포 비교 |
| 용신(用神) 궁합 | 서로의 용신을 돕는지 해치는지 | 용신 판정 + 비교 |
| 배우자궁 분석 | 일지(日支)의 합충 관계 | 일지 간 관계 분석 |

#### 레벨 3: 고급 궁합 (구현 난이도: 높음)
| 요소 | 설명 | 구현 방법 |

| 대운 동기화 | 두 사람의 대운 흐름이 맞는지 | 대운 계산 + 비교 |
| 도화살 분석 | 연애운·매력 요소 분석 | 신살 계산 |
| 홍란살/천희성 | 결혼운 관련 신살 | 신살 계산 |
| 십신 종합 분석 | 재성·관성 유무 및 강약 | 십신 분석 |

### 3.3 구현 가능성 평가
- **레벨 1 (기본 궁합)**: 1~2일이면 구현 가능. 룩업 테이블 기반.
- **레벨 2 (중급 궁합)**: 1주 소요. 사주 계산 라이브러리 활용 시.
- **레벨 3 (고급 궁합)**: 2~3주 소요. 명리학 전문 지식 필요.
- **AI 해석 레이어 추가**: 계산은 규칙 기반, 해석은 LLM에 위임하면 매우 효과적.

### 4.2 AI 강화 전략

#### 전략 A: 규칙 기반 계산 + LLM 해석 (추천)
```
[사용자 입력] → [사주 계산 엔진 (규칙 기반)] → [구조화된 데이터] → [LLM 해석] → [자연어 결과]
```
- 계산은 정확한 규칙 기반 엔진이 수행
- 해석은 LLM이 구조화된 데이터를 받아 자연어로 풀어줌
- 장점: 계산 정확도 보장 + 풍부하고 개인화된 해석
- 예: bazi-mcp의 MCP 서버 + Claude/GPT 연동

#### 전략 B: RAG 기반 명리학 지식 확장
- 명리학 고전(적천수, 자평진전, 궁통보감 등) 텍스트를 벡터 DB에 저장
- 사주 데이터를 쿼리로 관련 해석을 검색하여 LLM에 제공
- 전문가 수준의 깊이 있는 해석 가능

#### 전략 C: 궁합 특화 AI 에이전트
- 두 사람의 사주 데이터를 동시에 분석
- 관계 역학, 보완성, 주의점을 자연어로 설명
- "이 커플이 주의해야 할 시기", "서로에게 힘이 되는 영역" 등 실용적 인사이트

### 4.3 차별화 포인트 (기존 제품 대비)
1. **궁합 특화**: 대부분의 앱은 개인 운세 중심. 궁합/매칭에 깊이 집중하면 차별화.
2. **매칭 시스템**: 사주 기반 새로운 사람과의 매칭 (데이팅 앱 결합)
3. **시각화 혁신**: 두 사람의 오행/궁합을 아름답게 시각화
4. **대운 타이밍**: "언제 만날 사람이 좋은 인연인지" 시기 분석
5. **AI 대화형 해석**: 단순 결과 표시가 아닌, 대화로 깊이 파고드는 경험

## 5. 기술 아키텍처 제안

### 5.1 스택 구성

```
Frontend:     Next.js + TypeScript + Tailwind CSS
Backend:      Next.js API Routes (or separate Node.js server)
사주 계산:     manseryeok-js + bazi-calculator-by-alvamind (또는 자체 구현)
궁합 엔진:     자체 구현 (규칙 기반 점수 시스템)
AI 해석:       Claude API / GPT API (구조화된 프롬프트)
데이터:        KASI 음양력 데이터 (manseryeok-js 내장)
DB:            PostgreSQL (사용자, 매칭 데이터)
인프라:        Vercel / AWS
```

### 5.2 데이터 플로우

```
1. 사용자 A 생년월일시 입력
   ↓
2. manseryeok-js로 음양력 변환 + 절기 확인
   ↓
3. 사주 팔자 계산 (년주, 월주, 일주, 시주)
   ↓
4. 오행 분석, 십신 관계, 신살 계산
   ↓
5. 사용자 B 동일 과정 반복
   ↓
6. 궁합 엔진: 두 사주 비교 분석 (점수 산출)
   ↓
7. AI 해석 레이어: 구조화된 궁합 데이터 → LLM → 자연어 해석
   ↓
8. 결과 시각화 + 저장
```

| 명리학 전문성 부족 | 높음 | 명리학 전문가 자문 or 고전 텍스트 RAG |
| 궁합 해석의 주관성 | 중간 | 여러 학파 관점 종합, "참고용" 명시 |
| 법적 이슈 (점술업) | 낮음 | "엔터테인먼트 목적" 면책 조항 |

## 8. 결론 및 권고

### ✅ 기술적으로 충분히 구현 가능

**핵심 근거:**
1. **오픈소스 생태계가 성숙**: manseryeok-js(한국 특화), bazi-calculator-by-alvamind(글로벌), bazi-mcp(AI 연동) 등 충분한 기반 라이브러리 존재
2. **만세력 데이터 확보**: KASI 공식 데이터 기반, 1900~2050년 완벽 커버
3. **궁합 알고리즘 정량화 가능**: 전통 이론의 룩업 테이블 + 가중치 점수 시스템으로 구현 가능
4. **AI 시너지 극대화**: 규칙 기반 계산 + LLM 해석의 하이브리드가 최적. MCP 서버까지 이미 존재
5. **검증된 시장**: 점신 830억원 매출, 포스텔러 100억원+ — 시장이 이미 입증됨

### ⏱️ 2~4주 내 MVP 구현 가능

- **2주**: 사주 계산 + 기본 궁합 점수 + AI 해석 (최소 MVP)
- **3주**: 시각화 + 중급 궁합 + 사용자 기능
- **4주**: 고급 궁합 + 공유 + 론칭 가능 수준

### 🎯 추천 접근법
1. **manseryeok-js를 사주 계산 기반으로 채택** (한국 시장 최적화)
2. **궁합 엔진은 자체 구현** (차별화 핵심)
3. **AI 해석은 Claude API 활용** (규칙 기반 데이터 → 자연어 변환)
4. **궁합/매칭에 집중** — 기존 앱들은 개인 운세 중심이므로 "관계"에 특화하면 블루오션
