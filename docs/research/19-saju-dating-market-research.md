### 2-3. 한국 데이팅 앱의 핵심 문제점

1. **스와이프 피로감 (Swipe Fatigue)**: 끝없는 프로필 탐색에 지침
2. **신뢰성 부족**: 가짜 프로필, 사기 계정 문제
3. **안전 위협**: 이용자 24.2%가 "원치 않는 지속적 연락" 피해
4. **과도한 과금**: 호감 표시만으로도 상당한 비용, 낮은 매칭 확률
5. **비대칭 구조**: 접근은 쉬운데 거절도 쉬운 일회성 만남
6. **개인정보 유출 우려**: 이용자 16%가 개인정보 유출 경험

**핵심 인사이트:** 글로벌 트렌드와 마찬가지로 한국에서도 데이팅 앱 피로감이 심각. 79% Gen Z가 번아웃을 보고하고, UK에서만 2023-2024 사이 140만 명이 이탈. **"더 나은 매칭"에 대한 수요**가 폭발적.

## 3. 사주 데이터 & 기술적 타당성

### 3-1. 사주팔자 계산 원리

사주팔자(四柱八字)는 출생 시점의 4가지 기둥으로 구성:

| 기둥 | 구성 | 의미 |
|------|------|------|
| **년주 (年柱)** | 천간 + 지지 | 조상, 사회적 환경 |
| **월주 (月柱)** | 천간 + 지지 | 부모, 성장 환경 |
| **일주 (日柱)** | 천간 + 지지 | 본인, 배우자궁 |
| **시주 (時柱)** | 천간 + 지지 | 자녀, 말년 |

- **천간 (天干)**: 갑(甲), 을(乙), 병(丙), 정(丁), 무(戊), 기(己), 경(庚), 신(辛), 임(壬), 계(癸) — 10개
- **지지 (地支)**: 자(子), 축(丑), 인(寅), 묘(卯), 진(辰), 사(巳), 오(午), 미(未), 신(申), 유(酉), 술(戌), 해(亥) — 12개
- **오행 (五行)**: 목(木), 화(火), 토(土), 금(金), 수(水)
- **상생/상극 관계**: 목생화, 화생토, 토생금, 금생수, 수생목 / 목극토, 토극수, 수극화, 화극금, 금극목

### 3-2. 궁합 계산 방법

1. **띠궁합**: 년지(年支) 기반 12지지 궁합 (충/합/형/파/해)
2. **오행궁합**: 양측 오행 분포 비교 (상생 vs 상극 비율)
3. **일주궁합 (결혼궁)**: 일간(日干) 간의 합충 관계 — 가장 중요
4. **사주 전체 대조**: 년-년, 월-월, 일-일, 시-시 기둥별 비교
5. **장간(藏干) 분석**: 지지 내 숨은 천간까지 분석 (고급)

### 3-3. 오픈소스 라이브러리 & API

| 라이브러리 | 언어 | 특징 | GitHub |

| 지표 | 수치 |
|------|------|

### 4-3. 문화적 맥락

- **결혼 전 사주 궁합**: 한국 전통 혼례에서 사주 교환은 **필수 절차**였음. 현대에도 부모 세대에서 결혼 전 궁합을 보는 문화가 상당히 남아있음
- **MZ세대의 재해석**: MBTI처럼 사주/타로를 **자기 이해와 소셜 놀이**로 소비. "미신"이 아닌 "콘텐츠"로 인식
- **불확실성 시대의 수요**: 취업난, 경제 불안 속에서 미래 불확실성에 대한 심리적 안전장치로 사주 소비 증가
- **AI + 사주**: ChatGPT로 사주를 보는 트렌드 등장, AI 기반 사주 서비스가 전통 점집 시장을 잠식 중

**핵심 인사이트:** 사주는 한국에서 **비주류 취미가 아닌 주류 문화**. 특히 데이팅 타겟인 20-30대에서 68-90%가 운세를 경험하며, 여성(69.2%)이 남성(51.3%)보다 높은 관심도. 데이팅 앱의 핵심 타겟과 운세 소비층이 **거의 완벽하게 일치**.

### 5-2. Co-Star가 데이팅을 안 하는 이유 (추론)

Co-Star 현황:
- 다운로드: **2,000만+**
- 미국 MAU: **45만 명**
- 월 매출: **$80만**
- 연 매출: **약 $440만** (미국 $230만 + 해외 $210만, 2023)

Co-Star가 데이팅 기능을 추가하지 않는 것은:
1. **제품 포지셔닝**: 소셜/커뮤니티 앱이지 데이팅 앱이 아닌 브랜드 정체성
2. **양면시장 문제**: 데이팅은 특정 지역에 충분한 사용자 풀이 필요 (Struck 실패의 핵심 원인)
3. **규제/리스크**: Apple 앱스토어에서 점성술+데이팅 조합에 대한 심사 거절 이력 (Struck 사례)
4. **수익 모델 차이**: 운세 콘텐츠 구독은 안정적, 데이팅은 성공하면 사용자가 떠남

### 5-3. 실패 패턴 분석

글로벌 점성술 데이팅 앱들의 공통 실패 요인:

1. **사용자 풀 부족 (Critical Mass 미달)**: Struck는 LA, NYC, SF, 시카고만 서비스. 데이팅은 로컬 밀도가 핵심
2. **점성술이 "유일한 차별화"**: 매칭 이후의 경험이 일반 데이팅 앱과 차이 없음
3. **단발성 사용**: 궁합 확인 후 지속 사용 동기 부족
4. **앱스토어 심사 리스크**: 점술+데이팅 조합에 대한 플랫폼 정책 불확실성

## 7. 기회 분석 & 시사점

### 7-1. 한국 시장에서의 기회

**왜 한국에서 사주 데이팅이 작동할 수 있는가:**

1. **문화적 토양**: 84.5%가 운세를 경험한 나라. 점성술이 니치인 서구와 달리 사주는 **주류**
2. **MZ세대 친화**: 20-30대의 68-90%가 이미 운세를 소비. "재미"와 "자기이해" 관점에서 접근
3. **MBTI 선례**: 한국인은 이미 MBTI로 "유형 기반 궁합"에 익숙. 사주는 MBTI보다 **훨씬 풍부한 데이터**
4. **기존 데이팅 앱 피로**: 스와이프 피로감이 극심한 시점에 **"운명"이라는 새로운 내러티브** 제공
5. **연애/결혼 문화**: 한국은 결혼 전 궁합을 보는 **실제 문화적 전통**이 있음
6. **기술적 가용성**: manseryeok-js 등 오픈소스로 사주 계산 즉시 구현 가능

**서구 점성술 데이팅 앱이 실패한 이유를 한국에서 극복할 수 있는 이유:**

| 서구 실패 원인 | 한국에서의 해결 |
|-------------|--------------|
| 점성술이 니치 문화 | 사주는 주류 문화 (84.5% 경험) |
| 사용자 풀 부족 | 한국은 단일 시장 (5,100만 인구, 도시 집중) |
| 차별화 부족 | MBTI+사주+AI 결합으로 깊은 호환성 분석 |
| 앱스토어 리스크 | "궁합팅" 등 한국 앱스토어에서 이미 승인 선례 |

### 7-2. 리스크 & 과제

1. **사용자 풀 확보 (콜드스타트)**: 초기 양면시장 문제는 여전히 존재
2. **궁합의 과학적 근거 부재**: Z세대는 "재미"로 소비하지만, 실제 매칭 품질이 떨어지면 이탈
3. **사주만으로는 부족**: 사주 궁합 점수가 높아도 실제 만남의 케미와 다를 수 있음
4. **수익 모델**: 궁합 확인 = 일회성. 지속적 과금 구조 설계 필요
5. **경쟁**: 기존 데이팅 앱이 궁합 기능을 쉽게 추가할 수 있음

### 7-3. 성공 가설

> "사주 궁합을 메인 매칭 알고리즘이 아닌, **스와이프 피로감을 해소하는 내러티브 레이어**로 사용하면 데이팅 앱 시장에서 차별화할 수 있다"

핵심 전략:
- 사주는 **아이스브레이커** (대화의 시작점)
- 매칭은 사주 + 행동 데이터 + AI 복합
- "운명적 만남"이라는 **스토리텔링**이 핵심 가치
- 매일 운세 + 궁합 업데이트로 **일일 방문 동기** 확보
